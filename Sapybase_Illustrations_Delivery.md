## How to Use These Illustrations

### Option A: Use the SVGs Directly (Fastest)
1. Copy the SVG files to your website assets folder
2. Embed them in your homepage HTML:
```html
<img src="/images/sapybase_hero.svg" alt="Sapybase vs Generic AI" />
```
3. SVGs are scalable — they'll look crisp at any size
4. Done! Deploy and test.

### Option B: Import to Figma for Customization (Most Flexible)

## Customization Examples

Want to tweak something? Here's how:

### Change colors
Find the hex codes in each SVG:
- `#4f46e5` = Blue (change to your primary color)
- `#10b981` = Green (change to your accent color)
- `#ef4444` = Red (for error states)

### Change icons
Replace emoji with:
- Your own custom icons (SVG code)
- Icon libraries (Font Awesome, Feather, Tabler)
- Illustrated characters

### Adjust spacing/sizing
Scale the entire SVG or modify `viewBox` dimensions:
- Wider? Change `viewBox="0 0 600 300"` to `"0 0 800 400"`
- Taller? Increase the middle number

### Add text
For web use, keep text OUT of the SVG. Instead:
- Position text via HTML/CSS overlay
- This keeps illustrations translation-ready
- Allows A/B testing of different copy

Before deploying, verify:

## FAQ

**Q: Why SVG instead of PNG?**  
A: SVGs scale infinitely, load faster, and are searchable by search engines. They're the web standard for illustrations.

**Q: Can I modify these myself?**  
A: Yes! Open the SVG files in any text editor. Find hex color codes, change them. For more complex edits, use Figma or Illustrator.

**Q: Will these work on mobile?**  
A: Yes. SVGs are responsive by default. Test on actual mobile devices to confirm.

**Q: Do I need Figma to use these?**  
A: No. You can use them directly as SVGs on your website. Figma is only if you want to customize them further.

**Q: What's the best way to test these?**  
A: Show them to 5 people who've never seen Sapybase. If 4+ understand the concept without explanation, they're working.
