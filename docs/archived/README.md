# Archived plans

Historical feature plans for work that has shipped.

**Do not treat anything here as current.**
These describe intent at the time of writing, not the state of the codebase.
Where an archived plan and the code disagree, the code is correct.

Verify against source and `git log` before acting on anything in this directory.
Kept for design rationale - why a tradeoff was settled the way it was - not as a specification.
